## Required Steps Before Submission

### 1. Generate Documentation

Run the following in R from the package root directory:

```r
# Install devtools if needed
install.packages("devtools")

# Generate documentation
devtools::document()

# Or directly with roxygen2
roxygen2::roxygenize()
```

This will create the .Rd files in the `man/` directory from the roxygen2 comments.

### 2. Run R CMD check

```r
devtools::check()

# Or from command line:
R CMD build .
R CMD check miter_*.tar.gz --as-cran
```

Address any WARNINGS, ERRORS, or NOTES that appear.

### 3. Common Issues to Check

- [ ] All examples run successfully
- [ ] No unexported functions are used in examples
- [ ] All imports are declared in DESCRIPTION
- [ ] No undefined global variables
- [ ] Package builds successfully on multiple platforms (Windows, Mac, Linux)
- [ ] All tests pass
- [ ] Vignette builds successfully
- [ ] README renders correctly

### 4. Update Version Number

When ready for CRAN submission, update version in DESCRIPTION:
- Remove `.9000` suffix
- Use semantic versioning (e.g., 0.1.0 for first release)

### 5. Spell Check

```r
devtools::spell_check()
```

Add any technical terms to `inst/WORDLIST` if needed.

### 6. Check URLs

```r
urlchecker::url_check()
```

Ensure all URLs in documentation are valid.

### 7. Build Vignettes

```r
devtools::build_vignettes()
```

Ensure vignettes build without errors.

### 8. Final Checks

```r
# Check package dependencies
devtools::check_dependencies()

# Check for reverse dependencies (if any)
devtools::revdep_check()

# Build source package
devtools::build()

# Build binary package
devtools::build(binary = TRUE)
```

### 9. Submit to CRAN

```r
# Submit to CRAN
devtools::release()

# Or manually upload to:
# https://cran.r-project.org/submit.html
```

### Code Quality
- [ ] R CMD check passes with no ERRORS, WARNINGS, or NOTES
- [ ] Code follows CRAN policies

### Testing

### Dependencies
